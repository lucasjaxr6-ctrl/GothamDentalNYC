# Gotham Dental — nova landing page

Proposta de landing page para a Gotham Dental (5 E 19th St, Union Square, NYC), feita pela Getê Marketing.

Site estático: `index.html` + `assets/css/styles.css` + fotos reais do consultório em `assets/img/`. Não precisa de build. Abra o `index.html` no navegador ou publique pelo GitHub Pages (Settings › Pages › branch `main`, pasta `/`).

## O que a página corrige em relação ao site atual

- **Visual genérico** → conceito "consultório-galeria": paredes brancas, tipografia serifada e legendas de museu nas fotos, que é o diferencial real da clínica.
- **Nota 4.9 escondida** → nota em destaque no topo e uma seção de avaliações.
- **Imprensa invisível** → faixa "As featured in" (NYT T Magazine, Financial Times, Entrepreneur, AACD, Whitney Museum).
- **Dois links de agendamento** → um único botão "Book online" em toda a página, mais uma barra fixa de Ligar/Agendar no celular.
- **Endereço, telefone e horário desencontrados** → um único bloco consistente em todo o site e no schema.org.
- **Títulos com palavras-chave em excesso** → título e descrição limpos, mais os dados estruturados `Dentist` para o Google.
- **Atendimento em português e espanhol escondido** → aviso no topo e uma faixa dedicada.

## Confirmar com a clínica antes de publicar

- O horário. O site diz seg–qui 9h–18h, mas alguns diretórios mostram sexta aberta.
- O link oficial de agendamento. Usamos o `book.modento.io/.../Gothamdental` do menu; o rodapé do site atual usa outro.
- Os convênios listados (Aetna, Cigna, Delta Dental, Guardian, MetLife), que vieram do Zocdoc.
- A autorização para usar os trechos de avaliações e as fotos.
- Fotos de antes e depois de casos reais, para uma futura seção de resultados.
